# Документация интеграции

## Архитектура
Выбрана восходящая стратегия. Сначала разработаны и проверены модули обработки и вывода. Затем добавлен модуль ввода и главный файл.

## Протокол взаимодействия
Модули общаются через локальный файл matrix_data.json (формат JSON). Это позволяет не связывать модули напрямую в коде.

## Потоки данных
1. Модуль ввода создает матрицу и записывает её в JSON.
2. Модуль обработки читает матрицу, считает вектор и записывает результат в JSON.
3. Модуль вывода читает итоговый вектор из JSON и показывает его.
