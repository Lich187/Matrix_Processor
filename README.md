# Название проекта: Matrix Processor
## Краткое назначение
Проект предназначен для обработки вещественной матрицы размерности n*m и формирования вектора b.
## Требования к окружению
- Python 3.8+
- Git
## Инструкция по запуску (предварительная)
1. Склонируйте репозиторий.
2. Запустите python main.py.

## Стратегия ветвления

В проекте используется стратегия **Git Flow** (базовый вариант).

- Ветка master — содержит стабильный код.
- Ветка develop — используется для разработки новых функций.
- Изменения вносятся в develop, после проверки сливаются в master.

Это позволяет вести параллельную работу и избегать конфликтов в основной ветке.
