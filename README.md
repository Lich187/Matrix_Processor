# Название проекта: Matrix Processor
## Краткое назначение
Проект предназначен для обработки вещественной матрицы размерности n*m и формирования вектора b.
## Требования к окружению
- Python 3.8+
- Git
## Инструкция по запуску (предварительная)
1. Склонируйте репозиторий.
2. Запустите `python main.py`.
